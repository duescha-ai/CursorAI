# Hamburg: Schulferien und Feiertage

Справочник для skill `vacation-search`. Семья ориентируется на **Гамбург**.

> Источники: [hamburg.de — Schulferien und Feiertage](https://www.hamburg.de/leben-in-hamburg/ferien-feiertage-termine-378818), [Ferienordnung Hamburg 2024–2030 (PDF)](https://www.hamburg.de/resource/blob/134372/5bc131bdd36a604f67b361d21f7df37e/ferienordnung-hamburg-2024-2030-data.pdf).  
> При расхождении или годах вне таблицы — сверяйся с официальными источниками.

## Правила для этого skill

| Окно | Использовать для отпуска? |
| --- | --- |
| **Sommerferien** | Да — главный длинный пляжный сезон |
| **Frühjahrsferien** | Да — только если вода > 24 °C и песок |
| **Maiferien / Himmelfahrt–Pfingsten** | Да — только если вода > 24 °C и песок |
| **Herbstferien** | Да — только тёплые моря с песком и водой > 24 °C |
| Незимние **Brückentage** взрослых | Да — короткие окна вне зимы |
| **Weihnachtsferien** / декабрь–февраль | **Нет** — зимний отпуск не учитывать |
| **Halbjahrespause** (конец января / начало февраля) | **Нет** — зима |

## Заметки по планированию

- Даты указаны как **первый и последний Ferientag** (школа не работает в эти дни включительно).
- Для снижения заполненности внутри Sommerferien предпочитай **края окна** (ранний старт после начала каникул HH или последняя неделя), избегай локальных пиков вроде Ferragosto (15.08), если они попадают в поездку.
- Reformationstag (31.10.) — законный праздник в Гамбурге; учитывай при стыковке Herbstferien / Brückentagen, но не строй вокруг этого зимний отпуск.
- При сомнении всегда перепроверяй актуальный год на hamburg.de.
